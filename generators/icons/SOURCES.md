# Icon sources

Downloaded 2026-11-09 for the module diagrams. Names are used as `icon` values: `k8s/pod`, `brands/python`, `aws/Amazon-EC2`.

| Folder | Source | Licence / terms |
|---|---|---|
| `k8s/` | github.com/kubernetes/community, `icons/png` (resources and infrastructure components, unlabeled, 256 px) | Apache 2.0 |
| `brands/` | simple-icons 13.21.0 via cdn.jsdelivr.net (SVG, recoloured and converted to PNG with resvg) | CC0 for the icon files; each logo remains its owner's trademark |
| `aws/` | AWS Architecture Icons package 07312026 from aws.amazon.com/architecture/icons (service icons 64@5x, group icons converted from SVG; group icons are named `group-<name>`) | AWS icon terms: use in architecture diagrams, do not alter the artwork |

`brands/openshift.png`: Red Hat OpenShift logo from simple-icons (redhatopenshift), recoloured red.
`brands/loki.png`: the Grafana Loki mark, cropped from `docs/sources/logo.png` in github.com/grafana/loki (AGPL-3.0 repository; the logo remains Grafana Labs' trademark).
