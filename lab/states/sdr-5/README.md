# SDR-5 start state: Detection as Code

Applied by `lab start` / `lab reset` in file-name order. `.sh` files run with bash and must be idempotent;
.yaml/.json files are applied with `oc apply -f`. Other files (python helpers and data folders) are read by the scripts and ignored by the loader.
Files in `reset.d/` run first on `lab reset` only.

Implemented: the files listed below.
- 10-ci-secrets.sh: secrets detections-ci and detections-ci-ca in namespace build, from the lab variables.
- 20-gitea-repo.sh: private Gitea repository detections with the starting files from repo/ (two finished detections, recorded samples for three, the helper scripts in ci/ (including probe.py for step 5 and check_rule.py, an offline check of a rule file against its samples), and the Tekton Task ci/task.yaml, stored here as ci_src/task.yaml.tpl). repo/ is generated by make_repo.py from ci_src/, lokilib.py, replay.py and the SDR-4 scenarios.
- 30-grafana-routing.sh: Mattermost contact point, default route and the siem-detect folder.
- 40-preflight.sh: read-only checks for Tekton and the Mattermost token secret.
- 15-reference.sh: copies the reference answer for the pod-exec rule exercise (reference/pod-exec.json) to /workspace/sdr-5/reference/ in the lab shell; outside the repository clone, so the learner does not see it by accident.
- reset.d: removes the pipeline, the det-* rules and the repository.

The learner writes rules/pod-exec.json (a scaffolded exercise: the learner writes the four filters of the query and the expected result of three tests; the reference answer is reference/pod-exec.json, tested with ci/check_rule.py offline), ci/run_tests.py, ci/deploy.py, the Pipeline (ci/pipeline.yaml), and ci/measure.py. The replay and test path was tested against a local stand-in for Loki; the Gitea, Grafana, Mattermost and Tekton parts were not run.

Prerequisites: ENG-0 Terminal, Git and Your Lab, and SDR-4. Grafana, Loki, Mattermost, OpenShift Pipelines and Gitea come from the lab platform; the contact point and route are created here if missing.
